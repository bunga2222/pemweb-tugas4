Catatan Pertama Belajar HTML dan CSS

Ditulis oleh Bunga Mulia pada 22 Oktober 2026

Lima pertemuan pertama kuliah Pemrograman Web membuat saya sadar bahwa membuat halaman web tidak sesulit yang saya bayangkan, asalkan dikerjakan pelan-pelan dan dicoba sendiri.

Pertemuan pertama dimulai dari hal paling dasar: struktur dokumen HTML. Saya sempat lupa menutup tag <p> dan hasilnya tampilan halaman jadi berantakan. Dari situ saya belajar bahwa setiap tag pembuka harus punya pasangan penutup.

Setelah itu kami mengenal teks, daftar, tautan, gambar, tabel, dan formulir. Bagian yang paling saya suka adalah formulir, karena browser ternyata sudah bisa memeriksa isian kosong tanpa kita menulis kode tambahan.

Menurut dokumentasi MDN, HTML menyediakan struktur, sedangkan CSS mengatur bagaimana struktur itu ditampilkan.

Masuk ke CSS, saya belajar memisahkan tampilan ke file style.css. Dengan cara ini, satu perubahan warna cukup dilakukan di satu tempat dan berlaku untuk seluruh halaman. Saya juga baru paham kenapa aturan dengan id mengalahkan aturan dengan class: itu soal specificity.

Supaya tidak lupa, ini hal-hal yang saya catat dari materi CSS:

  • Selector elemen, class, dan id punya bobot yang berbeda.
  • Pilih maksimal dua jenis font agar tampilan tetap rapi.
  • Gunakan line-height agar paragraf nyaman dibaca.
  • Batasi lebar konten dengan max-width.

Bagi yang ingin belajar lebih jauh, tiga sumber ini membantu saya: MDN Learn HTML, MDN Learn CSS, dan Google Fonts untuk memilih jenis huruf.
